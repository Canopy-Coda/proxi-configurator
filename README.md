# Proxi Configurator — deployed site

This repository holds only the **built/deployed files** for the Proxi web
configurator, published via GitHub Pages. It is updated automatically by a
GitHub Actions workflow in the (private) source repository — do not edit or
open PRs here.

**Live site:** https://app.canopycoda.com (also served at
https://canopy-coda.github.io/proxi-configurator/)

Proxi is a custom MIDI controller for Chase Bliss pedals by Canopy Coda —
https://www.canopycoda.com
